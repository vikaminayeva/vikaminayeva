##  Главные проекты в моем портфолио

### 🗓 [Go Task Scheduler (Планировщик задач)]
**Полнофункциональный REST API веб-сервер с умным календарем повторений (Дипломный проект)**
*   **Стек:** Go, SQLite (`modernc.org/sqlite`), REST/JSON, JWT, Docker, Middleware.
*   **Суть:** Разработан кастомный движок вычисления дат (`NextDate`) для периодических задач. Интегрирована JWT-защита эндпоинтов, автоматическая инициализация базы данных с индексацией и многоэтапная сборка Docker-контейнера.

### 📡 [Morse HTTP Server]
**Веб-сервис для автоматического двустороннего декодирования файлов**
*   **Стек:** Go, `net/http`, `strings`, Multipart Forms, File I/O.
*   **Суть:** Сервер принимает файлы через веб-интерфейс, на лету выполняет контент-анализ строк, распознает тип данных (кириллица/Морзе) и генерирует на сервере новые файлы с результатом перевода.

### 📦 [Parcel Tracking Service]
**Backend-модуль логистического учета отправлений**
*   **Стек:** Go, SQLite, Repository Pattern, Integration Testing.
*   **Суть:** Сервис строго контролирует жизненный цикл посылок на основе СУБД, запрещая изменение адресов или удаление после смены статуса. Полностью покрыт интеграционными тестами.
