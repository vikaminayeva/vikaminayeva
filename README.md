### 📂 Портфолио проектов

####  [ToDo Server — Веб-сервис «Планировщик задач»]
*Проектирование архитектуры и интеграционных контрактов для распределенной системы.*
* **Что сделано:** Спроектировала REST API со всеми CRUD-операциями, задокументировала его в формате OpenAPI/Swagger (YAML) в качестве единого контракта для кросс-функциональной разработки.
* **Архитектурные решения:** Описала потоки данных между микросервисами через UML Sequence-диаграммы; спроектируя механизм JWT-аутентификации с валидацией входящих JSON-payload через схемы данных для защиты от некорректных запросов.
* **Стек / Артефакты:** REST, OpenAPI/Swagger, UML Sequence Diagram, JWT, JSON/XSD.

####  [Система отслеживания почтовых отправлений]
*Проектирование реляционной модели данных и техническое документирование.*
* **Что сделано:** Спроектировала ER-модель реляционной базы данных с нормализацией до 3NF для 6 ключевых сущностей, обеспечив отсутствие аномалий при масштабировании системы.
* **Анализ данных:** Разработала сложные SQL-запросы с использованием многоуровневых JOIN-соединений и агрегатных функций для вывода операционных метрик и мониторинга KPI системы в реальном времени. Сформировала базу знаний в Confluence.
* **Стек / Артефакты:** ER-диаграммы, PostgreSQL/MySQL, SQL (подзапросы, агрегация), Confluence.

#### [Тестирование API-сервера «Поиск кафе»]
*Анализ граничных условий, валидация требований и интеграционное тестирование.*
* **Что сделано:** Спроектировала и реализовала более 15 комплексных тест-кейсов для проверки HTTP-сервера. 
* **Обеспечение отказоустойчивости:** Проработала негативные сценарии и алгоритмы фильтрации/поиска, проверив валидацию GET-параметров при некорректном пользовательском вводе.
* **Стек / Артефакты:** HTTP (GET), Go, Тест-кейсы, Валидация параметров.
